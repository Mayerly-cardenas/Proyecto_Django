¿Qué es Django?

Django es un framework de desarrollo web escrito en Python, diseñado para crear aplicaciones de forma rápida, segura y escalable. Su lema es “The web framework for perfectionists with deadlines” (El framework web para perfeccionistas con plazos).

Este framework facilita la creación de aplicaciones web completas con autenticación, bases de datos, panel administrativo, y más, todo con pocas líneas de código.

Arquitectura MVT (Model - View - Template)

Django sigue el patrón MVT, similar al clásico MVC, pero adaptado al entorno Python:

  • Modelo (Model): Define la estructura de los datos y cómo se guardan en la base de datos.
  • Vista (View): Controla la lógica del programa y envía los datos al template.
  • Template: Define cómo se muestran los datos al usuario mediante HTML.

Instalación y Configuración Básica

  1. Instala Django con el comando: 
    pip install django
  2. Verifica la versión instalada: 
    django-admin --version
  3. Crea un nuevo proyecto: 
    django-admin startproject nombre_proyecto
  4. Inicia una aplicación dentro del proyecto: 
    python manage.py startapp nombre_app
  5. Ejecuta el servidor: 
    python manage.py runserver

Ventajas y Desventajas de Django

✅ Ventajas

  • Desarrollo rápido y limpio.
  • Seguridad avanzada (protección XSS, CSRF, SQL Injection).
  • Panel de administración automático.
  • Escalable para grandes proyectos.
  • Comunidad global y documentación extensa.

⚠️ Desventajas

  • Puede ser complejo para principiantes.
  • No ideal para proyectos muy pequeños.
  • Curva de aprendizaje intermedia.

Comandos Más Usados en Django

  • python manage.py runserver → Inicia el servidor local.
  • python manage.py makemigrations → Crea los archivos de migración de base de datos.
  • python manage.py migrate → Aplica las migraciones a la base de datos.
  • python manage.py createsuperuser → Crea un usuario administrador.
  • python manage.py shell → Abre una consola interactiva con el entorno Django.
